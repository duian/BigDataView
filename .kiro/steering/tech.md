# Tech Stack

## Core Technologies
- HTML5 / CSS3 / JavaScript (ES5/ES6)
- No build system - static files served directly

## Primary Libraries
- **ECharts** (v4.x/v5.x) - Main charting library for all visualizations
- **jQuery** (v1.10+) - DOM manipulation and AJAX
- **particles.js** - Background particle animations

## Common Utility Libraries
- digitalScroll.js - Number counter animations
- dataScoll.js - Data scrolling effects
- jcarousellite.js - Carousel/slider functionality

## Styling
- Custom CSS per template
- reset.css for browser normalization
- Dark theme color schemes (blues, cyans, greens on dark backgrounds)

## Assets
- PNG/SVG images for decorative elements and backgrounds
- Custom fonts in some templates

## Usage
```bash
# Clone and open any template directly in browser
git clone https://gitee.com/iGaoWei/big-data-view.git

# Or serve locally
python -m http.server 8000
# Then visit http://localhost:8000/web/
```

## Preview
- `view.html` - Root preview page with all templates
- `web/index.html` - Template listing page
- Each template has its own `index.html` entry point
